# HAU-439: horizontal slide between tabs

## What changed and why
- Native tabs (`expo-router/native-tabs`, react-native-screens 4.30.1) have no tab-change animation:
  UIKit swaps tabs instantly, and neither library exposes a prop for it.
- `patches/react-native-screens@4.30.1.patch` (bun `patchedDependencies` in `package.json` and
  `bun.lock`): `RNSTabBarController`, already its own `UITabBarControllerDelegate`, now returns a
  `RNSTabSlideAnimator` from `tabBarController:animationControllerForTransitionFromViewController:toViewController:`.
  The whole tab (native header and large title included) slides out while the new one slides in
  from the side of the tapped tab: 0.35 s, critically damped spring. Direction follows tab index,
  flipped when the controller's layout direction trait is RTL (the tab host sets that trait from the
  in-app language). Reduce Motion returns nil, so tabs switch instantly as before.
- The Liquid Glass tab bar stays native. Switching to JS tabs (`animation: "shift"`) would have
  dropped it, against the native-tabs decision (decisions.md 2026-10-30).
- Android unchanged (Material tabs switch instantly).

## Verification
- `bunx tsc --noEmit`, `bun run lint`: clean.
- Release build on `Paycheck Planner Dev` (iOS 27), screen recording during scratch Maestro flows,
  frames read one by one: Paychecks → Income slides left, Expenses → Paychecks slides right,
  the two pages stay edge to edge, the tab bar and each tab's FAB stay with their own page.
  Arabic (`-AppleLanguages (ar)`): directions mirrored (Income and Expenses come in from the left).
- `maestro test .maestro/qa/` on the same build: 6/6 passed (tab taps still settle in time).
- `rm -rf node_modules/react-native-screens && bun install --frozen-lockfile` re-applies the patch.
- Not checked: Reduce Motion on (code path returns nil, instant switch as before).

## Follow-ups / pitfalls
- The patch is pinned to react-native-screens 4.30.1; an SDK upgrade that bumps it must re-create
  the patch (`bun patch react-native-screens`, re-apply the hunk, `bun patch --commit`) and
  update the `patchedDependencies` key, or the patch no longer applies to the new version.
- Android: a slide for Material tabs would need a patch to react-native-screens' Android tabs host.
- `bun patch --commit` also re-hoisted unrelated lockfile entries (`@expo/ws-tunnel`); only the
  `patchedDependencies` block was kept.
