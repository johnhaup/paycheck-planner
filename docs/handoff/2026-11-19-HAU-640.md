# HAU-640: Light mode muted text readable

## What changed
- `src/constants/palette.ts`: Light `textMuted` is now `mutedGray` `#636366` (was `gray` `#9A9AA0`, removed as unused).
  It carries the unselected month pill and chart label/amount, paid bills' strike-through name and
  amount, "Linked", captions, section headers, placeholders, chevrons and the empty check circle.
- Contrast (WCAG): on the elevated pill `#E5E5EA` 4.77:1 (was 2.23), screen `#F2F2F7` 5.37 (was 2.51),
  white cards 5.99 (was 2.80), divider grey `#EFEFF4` 5.22.
- Why not the issue's `#6E6E73` (`darkGray`): only 4.04:1 on the `#E5E5EA` pill, below 4.5.
- Dark palette untouched (`slate500` already reads fine there).

## Pitfall
- Light `textMuted` (#636366) is now a touch darker than Light `textSecondary` (#6E6E73). Muted text
  stays quieter through size, weight and strike-through, not lightness. `textSecondary` itself is
  4.04:1 on `cardBackgroundElevated`; if it is ever used on that fill, it needs the same treatment.

## Verified
- `bunx tsc --noEmit`, `bun run lint` clean.
- Runner 2 (iPhone 17 Pro, iOS 27), dev build on Metro, scratch Maestro flow: fresh install → sample
  data → Settings → Light → Paychecks chart (Dec label, $5k), collapsed pills (Dec pill), paid rows on
  the Nov 20 card, Pay date detail (paid Groceries, "Linked"). All readable; selected Nov pill still
  stands out (bold, ink on green tint). Welcome (empty state) seen in Dark; Dark has no change.
