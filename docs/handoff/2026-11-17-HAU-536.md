# HAU-536: Light mode off switches have an invisible track (2026-11-17)

## What was wrong
`AppToggle` painted the off track with `colors.border`. In Light that is `lightGray` (#E5E5EA),
the same as `cardBackgroundElevated`, the Settings row, so an off switch was a white dot on grey.
In Dark `slate650` (#2E343D) sat one shade off `slate800` (#262B33), so the track showed only faintly.

## Change
- New theme colour `toggleTrackOff`, used only by `AppToggle`'s off track: Light `switchGray`
  #C7C7CC (Apple's systemGray3), Dark `slate600` #434A55. Each one is visibly different from the
  elevated row (Settings) and from the modal background (Income Source form's "adjust to workday").
- `border` is unchanged; inputs and the other components that use it look the same as before.

## Verified
- `bunx tsc --noEmit`, `bun run lint`: clean.
- Release build (`expo run:ios --configuration Release`) on Paycheck Planner QA 27, scratch Maestro
  flow: Settings in Light and Dark (Hide cents, Payday and Unpaid bill reminders, all off) and the
  Income Source form in Dark (Semi-monthly, "Adjust to workday" off) all show the full track.
- Not looked at: the Income Source form in Light (#C7C7CC on the white modal, clearly darker) and
  the on state, which this change does not touch.

## Follow-ups / lessons
- Do not reuse `border` as a fill: in Light it equals the elevated row colour.
