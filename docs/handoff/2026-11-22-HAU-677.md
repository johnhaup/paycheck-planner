# HAU-677: Play: portrait screen feature optional

## What changed
- `plugins/withOptionalPortrait.js` (new, listed last in `app.json` plugins): a `withAndroidManifest` plugin
  that adds `<uses-feature android:name="android.hardware.screen.portrait" android:required="false"/>`, or
  sets `required="false"` on an existing entry. Same plugin as Apron's (HAU-676).
- Why: `"orientation": "portrait"` makes Play infer a required `screen.portrait` feature, which hides the
  app from tablets, Chromebooks and Android XR and shows a warning in Play Console. `orientation` is unchanged.
- Fixes HAU-718 (filed by the HAU-663 note), which is the same problem.

## Verified (Linux worker, 2026-11-22)
- `bunx tsc --noEmit`, `bun run lint` pass.
- `bunx expo config --type introspect`: `uses-feature` `android.hardware.screen.portrait`,
  `android:required: 'false'`; `.MainActivity` keeps `android:screenOrientation: 'portrait'`.
- `expo prebuild --platform android --clean`, `./gradlew :app:bundleRelease :app:assembleRelease
  -PreactNativeArchitectures=x86_64`.
- `bundletool 1.18.1 dump manifest --bundle app-release.aab`:
  `<uses-feature android:name="android.hardware.screen.portrait" android:required="false"/>`, and
  MainActivity `android:screenOrientation="1"` (portrait).
- `aapt dump badging app-release.apk`: `uses-feature-not-required: name='android.hardware.screen.portrait'`,
  no `uses-implied-feature` for the screen.
- Release APK on the `Pixel_9_Pro` AVD (API 35): Paychecks open, `accelerometer_rotation 0`,
  `user_rotation 1`, `adb emu rotate`: display stays `ROTATION_0`, 1280x2856, the screen renders in
  portrait. Reset `user_rotation 0`. The generated `android/` was deleted.

## Follow-ups
- Play Console's "Required hardware feature declarations" warning can only be checked after the runner's
  `android-release.sh` uploads the next AAB from `main`. Look at the release in Play Console then.

## Pitfall
- `aapt dump badging` does not read an `.aab`; use `bundletool dump manifest --bundle` (download the
  `bundletool-all` jar from GitHub releases), or build `assembleRelease` too and run aapt on the APK.
