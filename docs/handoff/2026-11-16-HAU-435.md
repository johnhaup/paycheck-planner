# HAU-435 Android build failed @ 188aa01 (submit)

## What failed
Two separate problems in the Android release run `2026-11-16-090801` (linux worker):

1. **Gate: `expenses.yaml` failed twice** (`Tap on ".*Internet.*"` → `"e.g. Electric Company"` not visible).
   On the Android screen the Internet sample bill has a payment link, and its icon button's label
   is "Open payment link for Internet". The regex `.*Internet.*` matched that button and Maestro
   tapped it, so Chrome opened ("Welcome to Chrome", the issue's screenshot and `final.png`)
   instead of the bill form. On iOS the tap reached the row, which is why the iOS gate passed.
   The app is fine; the flow selector was too loose.
2. **Submit: "The Google service account cannot submit this app."** No Play Console app exists yet
   for `com.johnhaup.paycheckplanner` (see AGENT_CONTEXT, Android). Google refuses API uploads
   until John creates the app and uploads the first AAB by hand. Nothing in the repo can fix this.

## Change
- `.maestro/qa/expenses.yaml`: the Internet row's `scrollUntilVisible` and both `tapOn`s use
  `"Internet.*"` (anchored) instead of `".*Internet.*"`, so they match the row text and not
  "Open payment link for Internet". The asserts that include "Due the 18th" / "monthly" were already
  specific and stay as they were. `.*QA Water.*` has no link and stays the same.

## Verified
- `bunx tsc --noEmit`, `bun run lint`: clean.
- Not run on the emulator: another job's Gradle build was running on the worker, and the gate kills
  any emulator on the `runner` AVD. The next Android gate is the evidence.

## Follow-ups
- John: create the Play Console app and upload the first AAB in the console. Then grant
  `app-upload@haupenbusiness.iam.gserviceaccount.com` release permissions on the app. Until then
  every Android `submit` stage fails like this one.

## Lesson
- In a Maestro selector, `.*Name.*` also matches accessibility labels that contain the name
  ("Open payment link for X", "Mark X paid"). On Android those labelled buttons are tappable
  elements of their own. Anchor the regex to the row text (`Name.*`) whenever a row has buttons
  inside it.
