# HAU-777: Pay date detail, long bill-name words no longer shrink at AX sizes

**Cause**: HAU-773 made the check circle and − / + button bigger at accessibility sizes. The button sat beside the name, so a word plus the link icon no longer fit, and `AppWordWrapText` shrinks a word to the width it gets ("Payment", "Registration" at ~70%).

**Changed** (`PayDateExpenseRow`, only where `useAccessibilityTextSize()` is true)
- The − / + button moves from beside the name to the end of the amount line, so the name gets the full width right of the circle. Button size is unchanged from HAU-773 (scales with fontScale, capped 2x).
- Toggle extracted to a `toggle` const; amount line wrapped in `amountRow`. Default size renders the same tree order as before (button at the row end).

**Verified** (Runner 1, dev build, sample data, Brightline Co. Nov 27): AX XXXL dark: "Car Payment" and "Car Registration" both words at one size, circles one line tall, buttons larger and inside the card, link icon after "Payment". Default size dark: unchanged. tsc and lint clean.
Not checked: light mode at AX XXXL (layout does not depend on the theme), Android, other locales.

**Pitfall**: a cap on the button size alone (tried 1.5x) was not enough, "Payment" still shrank; the name needs the full row. Maestro screenshots only write inside its own output folder: use `simctl io screenshot`. At AX sizes the empty-state button is off screen, so load the sample data at the default size first.
