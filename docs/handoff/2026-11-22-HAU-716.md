# HAU-716: Expense sheet scroll-edge under the title bar

**What changed**
- `app/_layout.tsx`: `expense-form` options get `headerTransparent: true` and a transparent `headerStyle`.
- `app/expense-form.tsx`: the scroll view sets `contentInsetAdjustmentBehavior="automatic"`.

**Why**
The modal header had an opaque `headerStyle` background, so the form was clipped flat at the bar's
bottom edge and the "ICON" header looked sliced. With the bar transparent, iOS 26 paints its own
scroll-edge effect once content passes under it: blur plus a hairline. Unscrolled it is see-through,
so the bar looks as before.

**Verified** (Runner 1, iOS 27 dev build, Maestro for the swipes)
- AX XXXL dark and light: scrolled shows "AMOUNT" blurred under the bar with a hairline; unscrolled has none.
- `bunx tsc --noEmit` and `bun run lint` clean.

**Pitfall**
Setting only `headerStyle` transparent did nothing: the screen still started below the bar.
`headerTransparent: true` is what lets content go under it.
`simctl openurl` raises the "Open in…?" alert; open the form through the UI instead.

**Follow-ups**
The other modals (income form, settings, language, currency, paywall) keep the opaque bar. Same
fix if a long one gets flagged.
