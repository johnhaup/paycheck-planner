# HAU-617: Language and Currency sheets get a Close button

## What changed and why
- `app/_layout.tsx`: `languageOptions` and `currencyOptions` now set
  `headerRight: renderCloseButton`, the same X (Ionicons `close`, label `common.close`,
  `router.back()`) that Settings, the paywall and (since HAU-538) both forms use. Before, the only
  way out without picking was a swipe-down that nothing on screen suggested.
- Both pickers are pushed over the Settings modal, so Close goes back to Settings and leaves the
  saved choice alone. Swipe-down still works. No new strings.

## Verification
- `bunx tsc --noEmit`, `bun run lint`: clean.
- Dev build on Metro, Runner 1 (iPhone 17 Pro, iOS 27.0). A scratch flow (not committed) opens
  Language and Currency in Dark and Light, takes a screenshot of each and taps Close. Every time it
  lands back on Settings with "System default" still selected. The screenshots show the X at the top right.
- `.maestro/qa/settings.yaml` passes. Its `tapOn: "Close"` steps all run after the picker has
  already closed (a pick dismisses it), so the second "Close" never adds an ambiguous match.

## Not checked
- Accessibility text sizes, RTL and Android. All three use the shared button that Settings already has.
