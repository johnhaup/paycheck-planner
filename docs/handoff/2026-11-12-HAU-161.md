# HAU-161: Income at accessibility text sizes (2026-11-12)

## What changed
- `IncomeSourceRow`: at accessibility sizes (`useAccessibilityTextSize()`) the row stacks like
  `PaycheckCard`'s header: letter tile, then the name and schedule (both wrap instead of one line
  with "…"), then the amount and "per check". The amount is one line at every size and shrinks to
  fit (0.5 minimum) instead of breaking.
- Income summary tiles (`app/(tabs)/income/index.tsx`): at accessibility sizes "Per month" and
  "Next payday" are full-width tiles one above the other instead of two half-width ones, so the
  label wraps only between words. The values are one line and shrink to fit at every size.
- `AppLetterTile`: the letter caps Dynamic Type at 1.3×, the same rule as `AppDateTile` (text in
  a fixed-size box). This also covers the letter tiles on Expenses.
- Standard text sizes: no layout change.

## Verified
- `bunx tsc --noEmit` and `bun run lint` clean. Not run on a simulator (engineer runs have none).
