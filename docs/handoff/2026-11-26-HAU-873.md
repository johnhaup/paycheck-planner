# HAU-873: Expenses search icon invisible in light mode (Android)

**Changed:** `app/(tabs)/expenses/index.tsx` passes `headerIconColor` and `textColor` (both `colors.textDefault`)
in `headerSearchBarOptions`. The sort button already uses `colors.textDefault`, so both header actions share one
token per theme. Android's native search icon otherwise takes a default near-white tint; iOS ignores these props.

**Verified:** `bunx tsc --noEmit` and `bun run lint` pass. NOT verified on the emulator: the app installed on
`runner` is a Release build without dev client, and no APK exists on this machine, so no screenshots.

**Follow-up:** `hintTextColor` is left at the default; check the expanded search field in both themes on Android.
