# HAU-873: Expenses search icon invisible in light mode (Android)

**Changed:** `app/(tabs)/expenses/index.tsx` passes `headerIconColor` and `textColor` (both `colors.textDefault`) and
`hintTextColor` (`colors.textSecondary`) in `headerSearchBarOptions`. The sort button already uses `colors.textDefault`,
so both header actions share one token per theme. Android's native search view otherwise defaults to near-white tints
(icon, hint); iOS ignores these props.

**Verified:** `bunx tsc --noEmit`, `bun run lint`. Built a Release APK locally (`expo prebuild` + `gradlew
assembleRelease -PreactNativeArchitectures=x86_64`, ~4 min cold) and ran it on the `runner` emulator in light and dark:
header icons, expanded field, typed text. Before `hintTextColor` the light-mode hint and in-field magnifier were
near-invisible; fixed. Dark expanded field checked before the hint change only (default hint was readable); the
new hint colour (slate300) was not re-shot in dark.

**Round 3:** Dark expanded field showed the in-field hint magnifier dark-on-dark (react-native-screens draws it as a hint
span that `headerIconColor` cannot tint). Added `shouldShowHintSearchIcon: false` (the header already has the magnifier).
Rebuilt, re-shot dark empty + typed 'rent' and light empty: all readable.

**Pitfall:** the `android/` dir is generated and untracked-ignored; app theme is an in-app setting (Settings > Appearance),
not the system night mode.
