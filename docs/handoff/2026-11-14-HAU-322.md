# HAU-322: Settings toggle labels wrap between words at accessibility text sizes (2026-11-14)

## What changed
- `SettingsToggleRow`: at accessibility sizes (`useAccessibilityTextSize()`) the label takes the
  whole row and is an `AppWordWrapText`; the PRO badge (left) and the switch (right, where it
  always is) go on a line under it. Beside the switch and the badge the label had about half the
  row and iOS broke "reminder" at a letter ("Payday remind / er", "Unpaid / bill / remind / er").
  Same pattern as `SettingsLinkRow` from the earlier Settings text-size work.
- Stacking, not only `AppWordWrapText` beside the switch: with the badge and the switch in the
  row, "reminder" would have had to shrink at XXXL in English, and more in longer locales.
- Standard text sizes: the row is unchanged. No new strings.

## Verified
- `bunx tsc --noEmit` and `bun run lint` clean.
- `Paycheck Planner Dev` simulator (iOS 27.0), free user, dark theme, Accessibility XXXL: "Hide
  cents" on one line, "Payday / reminder" and "Unpaid bill / reminder" whole words, PRO badge
  bottom left, switch bottom right. Default size: Settings looks as before.
- Not checked: light theme (no colour changed), tapping a stacked switch (same `AppToggle`, same
  handler), Pro user (no badge: the switch sits alone on the right), other locales, RTL.
- No Maestro flow edited. `settings.yaml` runs at the default size, where nothing changed.

## For QA
- Settings at Accessibility XL and XXXL: the four toggle rows (Hide cents, Payday reminder,
  Unpaid bill reminder, Mark paid automatically) wrap between words; switches still toggle; a
  free user tapping a reminder switch still gets the paywall.
- `text-size.yaml` still has no Settings step; a Settings screenshot at XXXL would protect this.

## Lesson
- The Dev simulator had a Release build and no `ios/` in the worktree. To see a JS-only change
  without a 15-minute native build: `bunx expo export:embed --platform ios --dev false
  --bundle-output /tmp/x/main.jsbundle --assets-dest /tmp/x/assets`, copy it over
  `main.jsbundle` in the installed `.app` (path from `simctl listapps`), relaunch. Hermes runs
  the plain JS bundle. Keep the original and put it back afterwards.
- Maestro `takeScreenshot` files land in `~/.maestro/tests/<run>/<flow>/takeScreenshot/` when
  the flow is run from outside the repo.
