# HAU-714: segmented control pill in RTL

- `AppSegmentedControl`: since HAU-672 the pill used `left: layout.x`. `onLayout` x counts from the
  physical left, but RN turns `left` into `right` in RTL, so the pill sat on the mirrored segment.
- Fix: the track's width is measured (`onLayout`, shared value) and in RTL the pill's offset is
  `trackWidth - x - width`. LTR is unchanged. Works while the spring animates (computed in the animated style).
- Verified on `Runner 1` (iOS 27.0, dev build, Metro), sample data, `-AppleLanguages (ar)`:
  Expenses pill under الكل on open and under لمرة واحدة after tap; expense form for Rent pill under فاتورة.
  English: Expenses pill under All, form pill under Bill. `bunx tsc --noEmit` and `bun run lint` clean.
- Not checked by eye: the "Which paycheck" 30 pill in Arabic (same component, same code path).
- Lesson: RN absolute `left`/`right` flip in RTL but `onLayout` x never does; mirror it yourself
  (or use a transform) whenever a measured x feeds a positional style.
