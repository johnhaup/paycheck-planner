# HAU-316: Paychecks is one list through every month (2026-11-13)

## What changed
- `app/(tabs)/(paychecks)/index.tsx`: the list holds every month, oldest first (free: this month and
  next; Pro: six months back to eleven ahead). The selected month is the last one whose title reached
  the pinned header's bottom edge (`PaycheckCell` records each month's top in a shared value).
- Opens on the paycheck nearest today: launch, income back after Erase all data, rows added before
  it (buying Pro), tab selected again (`useSegments`). Chart taps, the calendar icon and the
  shortfall line jump the same way (`jumpTo`).
- The header collapses to the pills scrolling forward and comes back out scrolling back.
- "Past paychecks", `app/history.tsx`, `buildPastMonthGroups` and three strings (45 locales) are
  gone; the current month's totals cover the whole month. Free: `ProUnlockRow` after the last row
  and, when a source paid before this month, before the first.

## Merge with main (2026-11-14, PR #73 had gone conflicting)
- `buildMonthGroups`: HAU-329 counts the window from the month of the next paycheck. With
  `monthsBack` (the list) it now counts from this month when it has or had a paycheck, else from
  the next paycheck's month: free stays this month and next. Reminders (no `monthsBack`) keep HAU-329's rule.
- `app/history.tsx` stays deleted; HAU-163's wrap (`flexWrap`, centred label) moved to `ProUnlockRow`.
- Flows that opened `paycheck-planner://history`: `pro-text-size.yaml` scrolls to "See a full year of
  paychecks" instead (screenshots `pro-text-size-unlock-row-*`); the `smoke.yaml` step is removed.
- `large-title.yaml`: HAU-323's date-free selectors kept; no hop to the second month before the
  scroll (the list always continues); the pill tap asserts the jump and the hero, not the title.

## Pitfalls
- Every row stays mounted (`windowSize` 1000): estimated heights make a landed jump drift.
- A JS scroll can run a second late while rows mount: nothing after a jump is timed, a drag ends it.
- Reanimated's `Animated.FlatList` takes `CellRendererComponent`; hence `createAnimatedComponent(FlatList)`.
- A shared value set from JS reads back as its old value until the UI thread has it (`jumpingRef`).
- A PR that deletes a screen: after merging `main`, grep the flows for its deep link; others add steps.
