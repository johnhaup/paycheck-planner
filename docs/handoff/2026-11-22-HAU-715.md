# HAU-715: letter tile at AX XXXL

- `IconTile` (`src/components/expenseForm/IconPicker.tsx`) rendered the letter with `AppText` and no cap inside the fixed 44pt tile, so at AX XXXL the glyph outgrew it. Added `maxFontSizeMultiplier={1.3}` (15pt body → ~19.5pt, about the 20pt glyph icons beside it). At default size (multiplier 1) nothing changes.
- Verified on Runner 1 (dev build, iOS 27.0) at `accessibility-extra-extra-extra-large`: Expenses → Groceries → ICON, selected G fully inside the tile, and after picking the house icon the unselected G tile too. Size reset to `large` afterwards. `tsc` and `expo lint` clean.
- Lesson: at AX XXXL the first-run screen pushes "Try with sample data" off screen; a Maestro flow needs `scrollUntilVisible` before tapping it. `takeScreenshot` paths must stay inside Maestro's output folder; use `simctl io screenshot` for arbitrary paths.
