# HAU-641: Paychecks card bill rows at accessibility text sizes (2026-11-19)

## What changed
- `PaycheckExpenseRow`, stacked rows only (`useAccessibilityTextSize()`):
  - The check circle is one line of the name tall (`font.body × fontScale × 1.2`) and the row
    aligns to the top, so it sits on the name's first line instead of centred on the whole stack.
  - The link glyph and set-aside icon scale with the text (14pt × fontScale) and are attached to
    the name's last / first word, so the link sits right after the name ("Payment ↗").
  - The paid-row gap is gone: it came from the link icon sitting beside the word row, which then
    measured an extra line; the amount now sits 8pt under the name.
- `AppWordWrapText`: optional `leading` / `trailing` nodes, laid out in a no-wrap row with the
  first / last word (and beside the text in the unspaced-script fallback).
- `AppCheckCircle`: optional `size` (default 22, checkmark scales with it).
- Standard text sizes: unchanged (same JSX path, same 22pt circle, 14pt icons).

## Verified
- `bunx tsc --noEmit`, `bun run lint` clean.
- Dev build on `Runner 2` (iOS 27), sample data, scratch flows: AX XXXL dark and light, AX M dark,
  default size. Circle on the first line, link after the name, amount directly under the name in
  the paid Car Payment row. Set-aside icon checked by temporarily making demo Savings a set-aside
  (reverted; set-aside is Pro so the free sample has none). Default size identical to before.
- `.maestro/qa/paychecks.yaml` on the dev build: passes.

## Follow-ups
- `PayDateExpenseRow` (pay date detail) and `ExpenseRow` (Expenses) still put the link icon
  beside the word row, so it drifts to the trailing edge when a name wraps; the detail's circle
  is still 22pt. `leading` / `trailing` on `AppWordWrapText` is the fix there too.

## Pitfalls
- At XXXL the onboarding's "Try with sample data" is below the fold: `scrollUntilVisible` first.

  `~/.maestro/tests/<run>/<flow>/takeScreenshot/`. Other jobs' runs share that folder.
- simctl appearance does not change the app; Light is the in-app Settings segment.
