# HAU-163: PRO controls stay on screen at accessibility text sizes (2026-11-13, updated 2026-11-14)

## What changed
- Past paychecks (`app/history.tsx`): the "See earlier months" row wraps. The label takes at most
  the row's width and breaks between words; the badge and chevron move to a second centred line
  when they do not fit beside it. Applies at every size, so a long translation wraps as well.
- Add expense ("Set-aside" + PRO badge): fixed on `main` by the Settings / segmented control
  text-size ticket (#67), which merged first. Round 1 of this branch had its own stacking
  `AppSegmentedControl`; it conflicted, so on 2026-11-14 `origin/main` was merged into the branch
  and `main`'s control kept as is. This branch no longer touches `AppSegmentedControl.tsx`.
- Branch diff against `main` is now `app/history.tsx`, QA's flows (`pro-text-size.yaml`,
  `smoke.yaml`) and this note.

## Verified
- `bunx tsc --noEmit` and `bun run lint` clean on the merge result.
- Not run on a simulator by the engineer. QA round 1 saw the `history.tsx` change working at XL
  and XXXL on the pre-merge branch, and `main`'s Add expense stacked and whole; the merged
  combination is unseen.

## For QA
- Free tier, Accessibility XL and XXXL. Paychecks → Past paychecks (or `paycheck-planner://history`):
  "See earlier months" whole, nothing cut at either edge, badge and chevron on screen; tapping
  opens the paywall.
- Expenses → + : "Bill" and "Set-aside" stacked, "Set-aside" whole, PRO badge inside its row
  (this is `main`'s behaviour now). `pro-text-size.yaml` asserts Set-aside below Bill; it was
  written against the old branch control, so rerun it on the merge.

## Follow-ups / pitfalls
- The open continuous-list PR (#73) removes the History screen and puts "See earlier months" in
  the Paychecks list. Whichever merges second must carry the wrap over (or drop `history.tsx`
  and the history steps in `pro-text-size.yaml` / `smoke.yaml`).
- A pushed branch that conflicts with `main`: merge `main` in, never rebase (no force-push).
- Yoga only shrinks an item within its line: `flexWrap: "wrap"` plus `flexShrink: 1` on the text
  gives "wrap the label when it is alone on a line, otherwise move the badge down".
