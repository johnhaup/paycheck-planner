# HAU-865: Android nav bar in dark mode, Settings bottom padding

- `app.json`: `expo-navigation-bar` plugin with `enforceContrast: false`. Without it Android draws a pale
  grey scrim behind the 3-button bar (edge-to-edge, SDK 58); with it the bar is transparent, so the
  screen's own background (and the tab bar) shows through, as the status bar already does.
- `app/_layout.tsx`: `<NavigationBar style=... />` (Android only) sets light buttons in dark, dark in light.
- `app/settings.tsx`: on Android the scroll content's bottom padding is the safe-area bottom inset + 16dp
  (`MEASUREMENTS.spacing.lg`). iOS keeps `spacing.bottom` (the sheet has its own inset).
- New dependency `expo-navigation-bar` (native, so needs a new Android build; no iOS effect).

Verified: tsc, lint, Release build on the `runner` emulator (3-button nav), dark mode: Settings scrolled to
the end shows Erase all data and both footnote lines above the bar; Expenses tab bar and nav bar match.
Not checked: light-mode end-of-list screenshot (padding is mode-independent), gesture navigation.

Pitfall: `NavigationBar` style only works when the plugin's `enforceContrast` is false.
