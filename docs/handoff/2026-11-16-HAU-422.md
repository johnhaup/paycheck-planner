# HAU-422: en-CA keywords use all 100 characters

## What changed
Store listing metadata only, no app code. `ship/listing/en-CA.json` keywords gain `weekly` before
`biweekly`: 93 → 100 characters. The keyword pass for the Nov 2026 subtitle/keyword rewrite dropped both `savings` and
`weekly` from the en-CA field, but one drop was enough. With `weekly` back, Canada gets the
"weekly budget" phrase (keyword + title word) the same as en-US. `savings` stays out (it would be 108).

## Verified
Script check: keywords exactly 100 characters (all ASCII), file parses as JSON, no word repeats across
title "Paycheck Planner: Budget", subtitle "Bill tracker for every payday" and keywords.
`bunx tsc --noEmit` and `bun run lint` pass. Not uploaded to App Store Connect here; the listing goes
up with the next release.

## Lesson
When trimming a keyword field over 100, drop one word at a time and recount; the comma-separated
length is easy to over-trim.
