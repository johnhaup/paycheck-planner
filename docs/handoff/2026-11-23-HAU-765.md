# HAU-765: minimum iOS version 17.0

## What changed and why
- iOS deployment target 16.4 → 17.0, so iCloud sync can use CKSyncEngine (brain `principles.md`,
  Cloud sync; HAU-760). Set in `app.json` → `expo-build-properties` → `ios.deploymentTarget: "17.0"`.
  SDK 58's default was 16.4 (`platform :ios, ... || '16.4'` in the template Podfile).
- `modules/layout-direction`: podspec floor 16.4 → 17.0, and the `#available(iOS 17.0, *)` guard in
  `setRTL` is gone (always true now).
- Users on iOS 16 keep the version they have installed but get no further updates; the App Store offers them the last compatible version.

## Verification
- `bunx expo prebuild --platform ios --clean` (pod install succeeded; no pod needs more than 17.0):
  - `ios/Podfile:27 platform :ios, podfile_properties['ios.deploymentTarget'] || '16.4'`
  - `ios/Podfile.properties.json:6 "ios.deploymentTarget": "17.0"`
  - `project.pbxproj`: the app target's Debug and Release (lines 393, 425) read `17.0`. The
    PBXProject-level defaults (497, 566) still read 16.4: `expo-build-properties` rewrites only
    the application target, which overrides them, and the project has no other target.
  - The built app's `Info.plist` has `MinimumOSVersion = 17.0`.
- `runner devapp` rebuilt the dev client (native side changed) on Runner 1, iOS 27.0: Build
  Succeeded, the app opens on Paychecks.
- `maestro test .maestro/qa/` on the dev build: 6/6 flows passed (8m 9s).
- By hand: Settings → Language → العربية flips the tab bar, title and Settings rows to RTL;
  back to English returns them to LTR.
- `bunx tsc --noEmit` and `bun run lint` pass.

## Notes
- The runner's shared dev build must be rebuilt for this branch (`runner devapp`), because the native side changed.
- Android was not built, because the diff has no Android input (`expo-build-properties` has no `android` key).
- Pre-existing build warning: `Locale.characterDirection(forLanguage:)` was deprecated in iOS 16
  (`LayoutDirectionModule.swift`). It is not new and is left alone here.
