# HAU-618: wrapped button labels centred

## What changed
- `src/components/AppButton.tsx`: the label's `AppText` gets `center`. `AppText` defaults to
  `textAlign: "start"` (HAU-167/172), so a label that wrapped to two lines filled the button's
  width and hugged the leading edge; the Pressable's `alignItems: "center"` only centred a
  single line. Every `AppButton` (filled, destructive, outline) is fixed by this one prop;
  `start` stays the default for all other text.

## Verified
- `bunx tsc --noEmit`, `bun run lint`: clean.
- Dev build on Metro, Runner 1 sim (iOS 27), launch argument
  `-UIPreferredContentSizeCategoryName UICTContentSizeCategoryAccessibilityXXXL`, scratch flows:
  Welcome ("Add income / source", "Try with / sample data"), empty Income ("Add income / source")
  and empty Expenses ("Add / expense") centred on both lines in Dark; empty Expenses in Light;
  the Add expense form's submit button (one line) still centred.
- Not looked at: the paywall at AX XXXL (same component, footer caps the label at 1.5x).

## Lesson
- Same as AGENT_LESSONS' HAU-167 line: inside a centred container, a wrapping `AppText` needs
  `center` itself; the parent's `alignItems` only positions the box.
