# HAU-446: polish pass, press feedback and list animations (2026-11-16)

## Found (walked Welcome, Paychecks, paycheck detail, Income, Expenses, Settings, sheets)
- No tappable element in the app had press feedback: rows, cards, buttons, chips, header icons,
  links and amounts all ignored the touch until the screen changed.
- Lists cut hard when they changed: adding or removing a bill on a paycheck's detail, deleting
  an expense or income source, Expenses filter and sort. Only the Paychecks cards animated
  (`PaycheckExpenseRow`).

## What changed
- `src/constants/press.ts`: `dimOnPress(style)` / `DIM_ON_PRESS` (content to 0.6 opacity while
  held, like a UIKit borderless button) and `highlightOnPress(style, color)` (a row's background
  while held, like a table cell). Palette token `rowPressed` (dark `slate700`, light `barGray`),
  a step above both card and elevated rows.
- Rows and cards highlight: Expense, Income source, Settings link and choice rows, a paycheck
  card's header, empty row and "Short by" row. Everything else dims: `AppButton`, `AppChip`,
  `AppCheckCircle`, `AppDatePicker`, icon picker tiles, swipe actions, header icons (gear,
  close, sort, Today), Mark all paid, date picker Cancel/Done, payment links, tappable amounts,
  add/remove on the paycheck detail, the Pro unlock row and the short-paycheck lines.
- `src/components/AppAnimatedListCell.tsx`: a `CellRendererComponent` (Reanimated `FadeIn`,
  `FadeOut`, `LinearTransition`) for the paycheck detail FlatList, Income FlatList and
  Expenses SectionList, each wrapped in `<LayoutAnimationConfig skipEntering>` so the first
  render does not fade in. Reduce Motion: Reanimated's default `ReduceMotion.System` skips them.
- Not touched: the Expenses segment pill (HAU-119), the Paychecks list and its scrolling
  (HAU-25, HAU-440), the tab slide (HAU-439), the FAB (HAU-438). No new strings or dependencies.

## Verified
- `bunx tsc --noEmit`, `bun run lint` clean. `.maestro/qa/` 6/6 on a Release build (Dev sim).
- Release build, `simctl io recordVideo` during scratch flows, frames read at 2-4 fps: Add Rent
  on a paycheck detail fades it in while the rows below slide; deleting Groceries fades it out
  while the rest slide up; long press on a paycheck card header and an Expense row shows the
  `rowPressed` background in dark (`#333A44`) and light (`#D4D4DA` measured, `barGray`).
- Not checked: Reduce Motion on (Reanimated's default skips layout animations), a real device.

## Pitfalls
- `CellRendererProps` is not re-exported by `react-native`; the cell declares the three props it
  uses. Reanimated's `Animated.FlatList` takes the cell renderer for itself, so a plain
  FlatList/SectionList with this cell is the way to animate a SectionList.
- Grouped rows round their corners by first/last; when the first or last row changes, the
  corners snap rather than animate.
