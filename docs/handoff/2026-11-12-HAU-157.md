# HAU-157: pay date detail at accessibility text sizes (2026-11-12)

## What changed
- `PayDateSummary`: the source name and long date sat in a column with no width limit beside the
  date tile, so they ran off the right edge instead of wrapping. The column now has `flex: 1`
  (wraps at every size), and at accessibility sizes (`useAccessibilityTextSize()`) the tile sits
  above the text so the name gets the full width. The "pay · bills" meta line shrinks and wraps
  beside its pencil, and the short row ("Short by … / Move a bill") stacks like `PaycheckCard`'s.
- `PayDateExpenseRow`: at accessibility sizes the bill name wraps instead of one line with "…",
  and "Linked" moves under the amount instead of taking width beside the name. The add/remove
  icon stays at the trailing edge (fixed 26pt, does not scale).
- Standard text sizes: the only difference is that a long source name now wraps instead of
  running off screen.

## Verified
- `bunx tsc --noEmit` and `bun run lint` clean. Not run on a simulator (engineer runs have none).

## For QA
- Largest accessibility size, sample data, open the first paycheck: header fully on screen, bill
  names whole ("Internet", "Savings", "Car Payment"), "Linked" below the amount, a short paycheck's
  "Move a bill" under "Short by". Check default size looks unchanged.
- `.maestro/qa/text-size.yaml` does not open the detail screen; no step was added because it could
  not be run here. Wrapping is a screenshot check anyway.
