# HAU-729 Expenses unfolded: each section is one card under its own header

- Before: on a regular-width screen (Pixel 9 Pro Fold unfolded, iPhone Duo unfolded, tablets) every section's
  rows were split down two columns while the section header spanned both, so totals floated over the empty
  right column and a section read as two cards.
- Now (`app/(tabs)/expenses/index.tsx`): wide layout is one SectionList item holding two columns of whole sections.
  `splitIntoColumns` puts each section, in order, in the column that is shorter so far (header counts as a row).
  Each column draws `AppSectionHeader` (total right-aligned to the card) above the section's rows, which keep
  `ExpenseRow`'s own grouped-card styling (`isFirst`/`isLast` per section). The SectionList's own header is empty in wide mode.
- Phone/folded path is unchanged (bills as items, native section headers).
- Verified: `bunx tsc --noEmit` and `bun run lint` clean. Not run on an emulator/simulator (Linux worker, no emulator run here).
- Trade-offs: wide mode is no longer virtualised per bill (one item); lists are small. Row add/delete animation in
  wide mode applies to the whole block, not per row.
